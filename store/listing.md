## Full description (both stores)
Tap an arrow and it slides off the board, but only if nothing is in its way. Bump into another arrow or a rock and you lose a heart. Find the right order and clear the whole board!

Arrowgami is easy to learn and hard to put down:
• Simple one-tap controls
• Endless levels, each one built so it can always be solved
• Long arrows that block whole rows and columns
• Rocks that never move, so plan your way around them
• Hints when you're stuck, and stars for flawless clears
• Play offline, anytime

Start with quick, cozy boards and work up to big brain-bending puzzles. How many can you clear with all three hearts?

## In-app purchases
Create these in App Store Connect (In-App Purchases) and Google Play Console (Monetize → Products → In-app products). The IDs must match exactly.

| Product ID | Type | Name | Suggested price |
| --- | --- | --- | --- |
| `arrowgami.removeads` | Non-consumable (Apple) / one-time (Google) | Remove Ads | $3.99 |
| `arrowgami.hints10` | Consumable | 10 Hints | $0.99 |
| `arrowgami.hints30` | Consumable | 30 Hints | $1.99 |

Apple needs a review screenshot for each purchase. The Shop screen (Level map → Shop) works for all three.
